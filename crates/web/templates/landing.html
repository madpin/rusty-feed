Architecture with opinions

Built around constraints, not slogans.

Rusty Feed treats an RSS reader as durable personal infrastructure. The design starts with what must remain true when one feed has one subscriber — or ten thousand.

01 / dedup

One article. One expensive pipeline.

Feeds, articles, extracted bodies, embeddings, and summaries are shared. Read state, folders, bookmarks, feedback, and preferences stay per-user. More subscribers do not mean more publisher fetches or LLM calls.

02 / durable

Postgres is the queue, not just the database.

Background work runs through an inspectable SKIP LOCKED queue with retries, leases, heartbeats, cron schedules, and a transactional outbox. A restart loses no job and invents no duplicate.

03 / optional

Intelligence is a layer, not a dependency.

Run local BGE embeddings or an OpenAI-compatible endpoint. Bring your own key for summaries. Disable embeddings and search becomes keyword-only. Lose Redis, Chromium, or an LLM and reading still works.

04 / boundary

The hostile web stays outside.

Publisher requests go through SSRF-guarded fetches and tracking cleanup. Article HTML is sanitized. Mutations are CSRF-protected. The interface ships under a strict CSP with no runtime CDN.

The machinery gets out of the way

Fast HTML when you read. Deep tooling when you need it.

Three reading modes, eight themes, keyboard navigation, installable PWA support, and normal links/forms that keep core flows usable without JavaScript.

Not a toy reader

Use the web UI — or plug into the system.

search/*

Meaning with an escape hatch

Hybrid PostgreSQL full-text + vector ranking, semantic-only search, saved searches, related articles, and a complete keyword-only mode when embeddings are disabled.

reader/*

Content, not publisher chrome

RSS/Atom/JSON Feed ingestion, conditional GET, readability extraction, per-feed selectors, tracking-pixel removal, media proxying, and isolated Live View.

api/v1

Your clients are welcome

A native scoped-token API plus GReader and Fever compatibility for Reeder, NetNewsWire, and the clients you already use. OPML moves your subscriptions in and out.

ops/*

Observable by default

Readiness and liveness endpoints, Prometheus metrics, structured tracing, durable run history, feed-health backoff, cost ledgers, quotas, and a read-only admin role.

auth/*

Multi-user without blurred boundaries

Local login, OAuth, passkeys, invitations, reverse-proxy identity, scoped API tokens, and tenant-aware queries. Shared content never turns into shared reading state.

deploy/*

One primary binary, explicit dependencies

Migrations and static assets are embedded. Run the worker in-process or separately. Compose ships Postgres, optional Redis, optional Chromium, and immutable GHCR images.
