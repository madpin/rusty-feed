A typical loaded process sits around 250–300 MB. The largest resident consumers are the local embedding model and ONNX runtime (loaded once into RAM), the SQLx/Redis connection pools, and template/asset buffers. Headless Chromium runs as a separate container, so it does not count toward this figure. To trim memory, set EMBEDDINGS_ENABLED=false if you don't need semantic/hybrid search or saved-search ranking (skips the model/ONNX runtime entirely), use a hosted embedding provider instead (EMBEDDING_PROVIDER=openai), or lower FEED_REFRESH_CONCURRENCY. Historical/container memory is also exported via Prometheus metrics.
